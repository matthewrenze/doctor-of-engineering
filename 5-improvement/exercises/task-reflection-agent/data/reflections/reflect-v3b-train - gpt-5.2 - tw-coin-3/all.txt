When a task provides an explicit long sequence of moves/actions, then keep an explicit step-by-step checklist or pointer and execute each command verbatim in order, avoiding exploration until the sequence is complete.  
When the instructions specify reaching a precisely named location before an action (e.g., picking up an item), then don’t act early or detour based on similar room names and wait until you’re in the exact named place.  
When a commanded move is impossible from the current location, then backtrack to the most recent junction or point where the route could have diverged and re-synchronize the remaining instruction sequence from the correct position instead of improvising.  
When the script includes “attempt” moves that are clearly impossible, then do only the minimum attempts needed to satisfy the script and immediately return to productive navigation toward the goal to conserve steps.  
When you’re in a dead-end or forced path (only one exit) and the instructed move is blocked, then take the only available exit and re-align to the planned route rather than repeating the blocked move.  
When repeated “take [item]” fails and “look” doesn’t show it, then stop retrying the same command and run high-information discovery/state commands (e.g., look, inventory, search/examine, objective recap) to confirm the exact item name and location before proceeding.
