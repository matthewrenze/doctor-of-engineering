# Darwin Godel Machine: Open-Ended Evolution of Self-Improving Agents

## Self-Improvement System Design (Darwin Gödel Machine)
- Self-referential agent code modification
- Empirical validation over formal proof
- Persistent archive of agent variants
- Open-ended evolutionary improvement
- Parallel exploration of multiple agent variants
- Alternating self-modification and evaluation phases
- Downstream task performance as improvement signal
- Accumulation of diverse agents as stepping stones
- Co-evolution of tools and workflows
- Use of frozen foundation models as internal capabilities

## Self-Modification and Evaluation Practices
- Programmatic editing of own agent code
- Benchmark-based evaluation of each variant
- Selection based on measurable performance gains
- Lineage tracking of agent modifications
- Cross-evaluation among archived agents

## Exploration and Search Strategy
- Exploration beyond the current best agent
- Branching from any archived agent state
- Preservation of diverse and suboptimal variants
- Avoidance of local optima via open-ended search

## Benchmark-Driven Improvement
- Use of concrete task benchmarks to define progress
- Optimization for real-world task performance
- Validation across multiple programming languages

## Safety and Oversight Practices
- Sandboxed execution of self-modifying agents
- Monitoring of behavioral and code changes
- Retention of human oversight and auditability

## Practical Implementation Practices
- Python-based agent code for full expressivity
- LLMs used for reasoning and code generation
- Incremental improvement of internal tools and workflows
