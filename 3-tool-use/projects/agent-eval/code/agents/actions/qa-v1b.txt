 - list_files()
   - description - lists the files contained in the current workspace
   - returns: string - a list the files contained in the current workspace
 - read_file(file_name)
   - description - reads the content of a specified file as text
   - arguments:
     - file_name: string - the name of the file to be read
   - returns: string - the first 10,000 characters of the file content
   - notes - supports pdf, pptx, docx, xlsx, html, csv, json, xml, txt, md, etc.
 - search_web(query)
   - description - searches the web for the given query
   - arguments:
     - query: string - the search query
   - returns: string - a list of the top 5 web search results for the given query
 - calculate(expression)
   - description - evaluates the mathematical expression using the eval() function in Python
   - arguments:
      - expression: string - the mathematical expression to be evaluated
   - returns: string - the result of the evaluated mathematical expression
 - finish(answer)
   - description - ends the task by providing a final answer
   - arguments:
     - answer: string - the final answer to be returned to the user
   - returns: string - the final score and correct answer
