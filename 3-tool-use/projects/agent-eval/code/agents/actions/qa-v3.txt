list_files() – lists files in the current workspace.
Use when you need to discover filenames before reading.

read_file(file_name) – reads the specified file as UTF-8 text.
Args: file_name (string).
Use when you know the exact filename.

search_web(query) – returns top 5 results (title, URL, snippet).
Args: query (string).
Use when external information or sources are needed.

calculate(expression) – evaluates a mathematical expression.
Args: expression (string).
Use only for arithmetic; do not execute code or strings.

finish(answer) – return the final answer and end the task.
Args: answer (string).
