# Pricing:
- Grounding with Bing Search - $35 per 1k queries
- Google Custom Search API - $5 per 1k queries
- Brave Search API - $3 / 1k queries
- SerpAPI - $10 / 1k
- DuckDuckGo - free (but rate limited and brittle)
- Google Search (GitHub library) - free but now depricated

# Notes:
- The Google Search API library no longer works as of 2025-09-10
Google deprecated text-based (headless) search tools
https://github.com/Nv7-GitHub/googlesearch

- Bing Search v7 has been depricated
Grounding with Bing Search is it's replacement
However, it's very expensive compared to the old Bing Search
