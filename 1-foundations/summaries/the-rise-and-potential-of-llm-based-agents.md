# Summary of The Rise and Potential of Large Language Model Based Agents: A Survey

## 1. Agent Design Principles

- Use LLMs as the agent's brain via natural language
- Enable autonomy through goal-directed behavior
- Enable reactivity through multimodal perception
- Encourage proactiveness through self-initiated actions
- Integrate pretraining knowledge for task performance
- Add memory modules for context retention
- Employ chain-of-thought prompting for reasoning
- Promote planning via multi-step decomposition
- Encourage generalization and transferability

## 2. Perception Best Practices

- Accept text input as the main communication medium
- Incorporate visual input for richer scene understanding
- Add auditory input for speech and sound-based tasks
- Extend perception with tactile, gestural, and sensor-based inputs

## 3. Action Best Practices

- Output text for communication, explanation, and feedback
- Integrate tool use for search, computation, and web actions
- Support tool understanding, execution, and creation by agents
- Enable embodied action in virtual or real environments for interaction 
- Design modular tools optimized for agent usability
- Enable self-debugging and tool creation by agents
- Provide demonstrations and examples for tool mastery
- Combine tools for expanded capability and autonomy 

## 4. Deployment Scenarios

- Single agent use
  - Task-oriented: follow instructions and complete goals
  - Innovation-oriented: explore novel domains and solutions
  - Lifecycle-oriented: adapt over time with continuous learning

- Multi-agent systems
  - Use disordered cooperation for diverse perspectives
  - Use ordered cooperation for structured collaboration
  - Include coordination agents or voting to consolidate responses

- Human-agent interaction
  - Instructor-executor: human directs, agent executes
  - Equal partnership: collaborate as peers
  - Ensure mutual understanding and feedback flow

## 5. Agent Social Behavior

- Behavior modeling
  - Input behavior: gather and process environmental signals
  - Internal behavior: reflect, plan, reason, learn
  - Output behavior: act on environment or communicate

- Personality modeling
  - Simulate cognitive traits, emotions, and moral values
  - Maintain identity consistency across interactions

## 6. Environment Design

- Text-based environments
  - Simulate interactions with structured narrative  

- Virtual sandbox environments
  - Enable exploration and role play in open worlds  

- Physical environments
  - Use embodied agents in real-world robotics or IoT tasks  

## 7. Evaluation Practices

- Utility
  - Evaluate task success rate and efficiency  
  - Assess foundational skills (reasoning, tool use, planning)  

- Sociability
  - Test language understanding and generation quality  
  - Measure communication fluency and appropriateness  

- Values
  - Ensure honesty, harmlessness, fairness, cultural fit  
  - Detect and mitigate biases and unsafe behaviors  

- Adaptability
  - Track continual learning and goal evolution  
  - Use simulated survival tasks to test evolution over time  

## 8. Safety and Trustworthiness

- Adversarial robustness
  - Defend against prompt attacks and poisoned inputs  
  - Use adversarial training and detection  
  - Introduce human-in-the-loop supervision  

- Trust and credibility
  - Incorporate process supervision for reasoning transparency  
  - Use external knowledge bases to reduce hallucination  
  - Apply calibration and debiasing techniques
